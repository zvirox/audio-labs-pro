# Audio Labs Pro — Keyboard Shortcuts Reference

Quick reference cheat sheet for Audio Labs Pro keyboard shortcuts and hotkeys.

---

## 1. Transport & Playback

| Shortcut | Action | Description |
|---|---|---|
| `Space` | Play / Pause | Toggle live timeline playback |
| `Home` | Rewind | Jump playhead back to timeline start (00:00.000) |
| `Esc` | Stop / Dismiss | Stop playback or close active modal/palette |

---

## 2. Command Palette & Navigation

| Shortcut | Action | Description |
|---|---|---|
| `Ctrl+K` | Command Palette | Open fuzzy command palette to search and execute any action |
| `F1` | Shortcuts Help | Open keyboard shortcuts help modal |
| `Ctrl+S` | Save Project | Save project file atomically and clear autosave copy |
| `Ctrl+O` | Import Audio | Open file dialog to import media |
| `Ctrl+Shift+R` | Reset Layout | Reset all panels to default docking and sizes |
| `Ctrl+D` | Toggle Theme | Cycle through Dark → Light → System appearance |
| `Ctrl+Shift+M` | Reduce Motion | Toggle animations and motion transitions |
| `Ctrl+1` .. `Ctrl+8` | Open Panel | Jump directly to panel (Mixer, Transport, Timeline, etc.) |

---

## 3. Timeline & Non-Destructive Editing

| Shortcut | Action | Description |
|---|---|---|
| `Ctrl+Z` | Undo | Revert previous timeline edit or parameter change |
| `Ctrl+Y` / `Ctrl+Shift+Z` | Redo | Reapply previously undone edit |
| `Ctrl+B` | Split Clip | Split clip at current playhead position |
| `Delete` / `Backspace` | Delete | Delete selected clip or in-out range |
| `Ctrl+C` | Copy | Copy selected range to clipboard |
| `Ctrl+X` | Cut | Cut selected range to clipboard |
| `Ctrl+V` | Paste | Paste clipboard range into active track |
| `R` | Ripple Toggle | Toggle automatic ripple editing on cuts and deletions |
| `Ctrl+A` | Select All | Select entire timeline extent |

---

## 4. Voice Lab & Dictation

| Shortcut | Action | Description |
|---|---|---|
| `Ctrl+Space` | Toggle Dictation | Start or stop live speech-to-text dictation |
| `Ctrl+Shift+T` | Transcribe Track | Run automated offline transcription on active track |
| `Ctrl+Enter` | Synthesize Line | Trigger speech synthesis for current dialogue line |
