# `alp-voice` / `sha256`

## Purpose

Provides a standalone, zero-allocation pure-Rust FIPS 180-4 SHA-256 cryptographic hash implementation for model checksum verification without external dependencies.

## Public API

- `digest(data: &[u8]) -> [u8; 32]`
- `digest_hex(data: &[u8]) -> String`
- `Sha256`: `new`, `update`, `finalize`

## Data flow

1. Data is fed into `update` in 64-byte blocks.
2. `finalize` appends standard bit-length padding and returns the 32-byte hash digest or lowercase hex representation.

## Allowed dependencies

Standard library only.

## Threading / real-time notes

Zero-allocation and safe for multi-threaded hashing of large model files in chunks.

## Error handling

Infallible computation over arbitrary byte slices.

## Testing

Unit tests in `sha256.rs` verify exact NIST standard test vectors for empty strings and canonical test sentences.

## Known limits

- CPU software implementation without hardware SHA extension instructions; optimized for model file verification.
